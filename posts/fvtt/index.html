FVTT部署指南

2025年3月18日·1560 字·4 分钟
Windows TRPG Server
作者
折り紙　紫藤
Prosper

导言
#

DND跑团平台在当前环境下主要使用枭熊地图和FVTT。二者各有利弊，枭雄地图的优点是无成本，便于使用，缺点是体验感不强，网络连接有时较为困难；FVTT的有点是本地化的部署能够保证连接的通畅，同时有广阔的社区模组和世界包、自动化支持，缺点是操作需要学习成本和部署和软件购买需要成本。本文作为我的备忘录，简述了在本地/Windows服务器中部署一个可用的FVTT并进行插件安装更新的过程。

所需资源
#

  • 公网IP（可能是家庭宽带也可能是服务器，如果仅在局域网内使用则不需要）
  • 云服务器（非本地部署时）
  • FVTT软件（需要50$USD（黑色星期五或者周年庆打折））

FVTT的安装部署
#

在本次实践中采用的是阿里云加载Windows Server 2025的2核2G云服务器（推荐2016版本以上），配置公网IP。如果对于Windows命令行较为熟练的情况下可以使用无GUI版本的系统，能够节省10G空间，如果不熟悉命令行建议还是装GUI版本，对于操作较为熟悉。

不同于Linux服务器使用SSH协议进行连接核使用SFTP协议进行文件的上传下载和连接，Windows服务器使用UDP协议进行远程桌面连接，相关的方法能够在阿里云文档上进行查阅，本文章只介绍一些简单的基本用法。

对于Windows服务器的连接有两种方式，一种是通过阿里云提供的Workbench进行连接，能够进行一些基本的操作，但是不能够进行文件的传输，文件传输需要使用Windows电脑自带的远程桌面，同时开通公网IP.在远程桌面中输入用户名和IP，并且输入密码，在资源设置中开启剪贴板，并将目标盘文件权限打开，即可将任意大小的文件通过复制粘贴传输到服务器中，同时通过远程桌面连接画质和操作都提升不少。

通过远程桌面进行连接后，将FVTT应用程序复制到服务器上，安装即可，在打开FVTT后，输入验证码即可开始使用。

插件和世界包和系统的安装
#

在社区和GitHub中存在各种的系统和插件，可以通过果园，FVTT中文社区，FVTT等渠道找到。同时相关的汉化和推荐插件清单能够在各种公开资料上找到，这里暂时不做赘述。

这三种包的安装方式是简单的复制替换，将相关包复制到user/thisuser/AppData/Local/Foundry Visual Tabletop/Data内，世界包放到world，模组放到module，系统放到system即可。

服务器基本安全
#

更改UDP端口
#

使用win+r运行regedit，找到路径HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\TerminalServer\Wds\rdpwd\Tds\tcp，将PortNumber修改成自定义端口。然后将HKEY_LOCAL_MACHINE\SYSTEM\CurrentContro1Set\Control\Tenninal Server\WinStations\RDP-Tcp的同样之修改为同一个端口，重启服务器即可

之后通过远程桌面连接时，输入IP:端口的方式进行连接。

修改管理员账号名
#

在一开始注册的时候可以将默认用户名Administrator修改成自己想要的名字以避免暴力碰撞。也可以通过运行gpedit.msc找到计算机配置>windows设置>安全设置>本地策略>安全选项>账户：重命名系统管理员账户进行改名即可。

笔者并无网络安全相关知识，可以在其他相关资源中找到更加高级的网络安全方法。

结语
#

FVTT作为跑团软件，绝非能用容易使用概括。但是他的优点是相对于其他跑团软件独特的自部署优势和其较为完善的社区支持和自动化支持。笔者尚且刚开始使用，只能算得上是初学者。实际使用体验在带完一些团之后会另开文章讲述。
